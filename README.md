# 🏥 Medical Reminders System (Система медицинских напоминаний)

Данный проект представляет собой информационную систему для контроля приема лекарственных препаратов пациентами с хроническими заболеваниями. Система позволяет врачам назначать лечение, а пациентам — получать структурированное расписание приемов.

## 🚀 Технологический стек
- **Язык программирования:** Python 3.11
- **Реляционная БД:** PostgreSQL 16 (хранение основных данных, связей и бизнес-логики)
- **NoSQL БД:** Redis (кэширование данных о препаратах и управление сессиями)
- **Инфраструктура:** Docker Compose (для быстрого развертывания БД)
- **Архитектура:** Layered Architecture с использованием паттерна **Repository**.

## 🛠 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/Ramzikkkk/medical-reminders-db.git
cd medical-reminders-db
```

### 2. Запуск баз данных
Убедитесь, что у вас установлен и запущен **Docker**.
```bash
docker compose up -d
```

### 3. Настройка окружения
Создайте виртуальное окружение и установите необходимые зависимости:
```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
```

### 4. Инициализация данных
Если базы данных пусты, выполните скрипты инициализации из папки `kr/db/` (или используйте `lab1/init_db.sql` через psql):
```bash
docker exec -i medical_db_postgres psql -U postgres -c "CREATE DATABASE medical_reminders;" || true
docker exec -i medical_db_postgres psql -U postgres -d medical_reminders < kr/db/init_db.sql
```

### 5. Запуск приложения
```bash
python3 kr/src/main.py
```

## 📖 Инструкция по взаимодействию с системой

Приложение представляет собой консольный интерфейс с основным меню:

### 👥 Управление пациентами (Patients Management)
- **Просмотр списка:** Вывод всех зарегистрированных пациентов.
- **Добавление:** Создание нового профиля пациента.
- **Редактирование/Удаление:** Обновление данных или удаление записи.

### 💊 Управление назначениями (Prescriptions Management)
- **Просмотр назначений:** Вывод всех активных курсов лечения. Система автоматически заменяет ID пациента на его полное имя (используя `JOIN`).
- **Создание назначения:** Привязка пациента к врачу с указанием сроков лечения.

### 🔑 Сессии и Кэш (Redis)
- **Сессии:** Создание временного токена доступа для пользователя.
- **Кэш препаратов:** Быстрый доступ к информации о лекарствах без обращения к основной БД.

### 📊 Функциональные отчеты
- **Расписание пациента:** Введите ID пациента, чтобы получить полный список препаратов, время их приема и дозировку.
- **Статистика:** Поиск по названию препарата для определения количества пациентов, принимающих его.
