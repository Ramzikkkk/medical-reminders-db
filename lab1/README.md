# Medical Reminders Database Project

Система напоминаний о приеме медицинских препаратов.

## Состав проекта:
- `init_db.sql` — Скрипт инициализации структуры базы данных (PostgreSQL).
- `seed_data.sql` — Тестовые данные для наполнения базы.
- `docker-compose.yml` — Конфигурация для быстрого развертывания БД через Docker.
- `lab1_report.md` — Отчет по лабораторной работе №1.
- `main.py` — Основной файл приложения (в разработке).

## Запуск проекта:
1. Запустите базу данных: `docker-compose up -d`
2. Выполните скрипты инициализации и наполнения в DBeaver или через psql.
